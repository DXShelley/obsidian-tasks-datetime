在 Markdown 里工作

精确，不复杂。

01

可选秒级时间

支持 YYYY-MM-DD HH:mm:ss，也可继续只使用日期。

02

创建与编辑

在任务编辑时使用整合的日期与时间选择器，减少手动输入。

03

查询与概览

按时间查询任务，在今天、本周和本月视图中查看安排。

04

重复与优先级

保留重复任务预设和重要性、紧急性编辑方式，适应既有习惯。

可核验的边界

你的任务，留在你的 vault。

插件通过 Obsidian Vault API 读取和修改当前打开 vault 中的任务 Markdown、插件设置及相关元数据，用于渲染、查询、创建、编辑与统计。

当前分发方式

从 Release 手动安装。

  1. 1

    从项目 Release 下载 main.js、manifest.json 与 styles.css。

  2. 2

    在 vault 中创建 .obsidian/plugins/obsidian-tasks-datetime/。

  3. 3

    复制三个文件并在 Obsidian 中启用 Tasks Datetime。

该项目目前不在 Obsidian Community Plugins 目录中。请仅从本项目的 GitHub Releases 获取构建文件。
