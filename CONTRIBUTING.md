# Contributing to Tasks Datetime

## Thank you

Thank you for wanting to contribute to Tasks Datetime!
Every contribution is much appreciated!

## Before opening a pull request

- Open an issue in this repository before starting a substantial change.
- Work on a branch based on `dev` and include focused tests for behavior changes.
- Run `fnm exec --using=22.23.1 corepack yarn test --runInBand` and `fnm exec --using=22.23.1 corepack yarn lint:no-fix`.
- Do not submit upstream branding, screenshots, sponsorship links, or claims of affiliation.
- By contributing, you agree that your contribution is available under this repository's MIT license.

This is an independently maintained derivative of [obsidian-tasks-group/obsidian-tasks](https://github.com/obsidian-tasks-group/obsidian-tasks). Please direct upstream-plugin issues and requests to the upstream project.
