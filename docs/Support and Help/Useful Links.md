Tasks Datetime is an independently maintained derivative focused on optional
time-of-day and seconds precision. It is not affiliated with or supported by
the upstream Obsidian Tasks project. For the official upstream plugin, see
[obsidian-tasks-group/obsidian-tasks](https://github.com/obsidian-tasks-group/obsidian-tasks).
